# OtoWake BG（おとわけびーじー）のダウンロード

[English](../en/README.md)

**いまの版は 0.1.0（ベータ版）です。** 機能を絞った最初の版で、正式版の前に、使ってみた感想や不具合を集めるためのものです。動きや画面は、これから変わることがあります。

OtoWake BG は、ブルーグラスを演奏する人のための、無料の練習アプリです。いま鳴っている曲を、ボーカル、バンジョー、マンドリン、フィドル、ドブロ、ギター、ベースなどのパートに分けて鳴らし直します。弾きたいパートを小さくすれば、その録音があなたの伴奏になります。

できることと、使う前に知っておいてほしいことは、[リリースノート](release-notes.md)にあります。使い方は、[Mac 版の手引き](manual-mac.md)と[Windows 版の手引き](manual-windows.md)にあります（どちらもアプリの「ヘルプ」からも開けます）。

インストーラーの画面は、パソコンの言語に合わせて日本語か英語で出ます。アプリの言語は、あとから設定で変えられます。

> [!CAUTION]
> **OtoWake BG のインストーラーとアプリには、Apple や Microsoft の開発元の署名がありません。** 個人で作り、無料で配っているためです。ダウンロードしたときや、はじめて開くときに、Mac や Windows が「確認できない」という警告を出します。下の手順で開けます。

## Mac でのインストール

1. `OtoWakeBG-0.1.0-mac.pkg` をダウンロードして、ダブルクリックします。
2. 「“OtoWakeBG-0.1.0-mac.pkg”は開かれませんでした」と出たら、「完了」を押します（「ゴミ箱に入れる」は押さない）。
3. アップルメニューの「システム設定」を開き、「プライバシーとセキュリティ」を選びます。
4. 下のほうの「セキュリティ」に、「“OtoWakeBG-0.1.0-mac.pkg”は、Mac を保護するためにブロックされました」と出ています。その横の「このまま開く」を押します。
5. もう一度確認が出たら「このまま開く」を押し、Mac のログインパスワード（または Touch ID）で許可します。
6. インストーラーが開きます。「続ける」を押して進み、「インストール」を押します。
   - 「インストール先」で「自分専用にインストール」を選ぶと、管理者のパスワードなしで、ホームの「アプリケーション」フォルダに入ります。
7. 終わったら、「アプリケーション」フォルダの OtoWake BG を開きます。メニューバーにアイコンが出ます。

macOS 14 では、手順 2〜5 の代わりに、`.pkg` を Control キーを押しながらクリックして「開く」を選ぶと開けます。

アプリを開くときにも同じ警告が出たら、手順 3〜5 と同じように「このまま開く」を押してください。

## Windows でのインストール

1. `OtoWakeBG-Setup-0.1.0-win-x64.exe` をダウンロードします。
   - Microsoft Edge で「一般的にダウンロードされていません」と出たら、その行の「…」から「保存」を選び、続けて出る画面で「詳細表示」→「保持する」を選びます。
2. ダウンロードしたファイルをダブルクリックします。
3. 「Windows によって PC が保護されました」と出たら、「詳細情報」を押し、出てきた「実行」を押します。
4. セットアップの画面で、デスクトップにショートカットを作るかを選び、「次へ」「インストール」「完了」と進みます。管理者の権限は要りません。
5. OtoWake BG が起動します。スタートメニューの「OtoWake BG」からも起動できます。

### スマート アプリ コントロールが「オン」の PC では動きません

> [!CAUTION]
> **Windows 11 の「スマート アプリ コントロール」が「オン」になっている PC では、署名のないアプリは止められ、OtoWake BG は動きません。** 警告と違って、手順で開くことはできません。

確かめ方：スタートメニューで「Windows セキュリティ」を開き、「アプリとブラウザー コントロール」→「スマート アプリ コントロールの設定」を見ます。「オン」のときは、この版は使えません。

スマート アプリ コントロールを「オフ」にすると、Windows を入れ直すまで「オン」に戻せません。OtoWake BG のためにオフにすることは、おすすめしません。

## ファイルを確かめる（SHA-256）

ダウンロードしたファイルが、配布したものと同じかを確かめられます。下の値と、自分のパソコンで計算した値が同じなら、途中で書き換えられていません。

| ファイル | SHA-256 |
|---|---|
| `OtoWakeBG-0.1.0-mac.pkg` | `264fb6b7ba328f8bac5325b76d21a9d9eadaabe98596788afaa05f7b2af8a65d` |
| `OtoWakeBG-Setup-0.1.0-win-x64.exe` | `efbd9b48cb6dedb2e688709aafa872d38e02bf1679f0cc04166e24463c176d41` |

- Mac：「ターミナル」で、`shasum -a 256 ` と入力してから（最後に空白を 1 つ）、ダウンロードしたファイルをウィンドウにドラッグし、return キーを押します。
- Windows：ダウンロードしたフォルダーで右クリックして「ターミナルで開く」を選び、`certutil -hashfile OtoWakeBG-Setup-0.1.0-win-x64.exe SHA256` と入力して Enter キーを押します。

## アンインストール

- Mac：OtoWake BG を終了してから、「アプリケーション」フォルダの OtoWake BG をゴミ箱に入れます。設定とデータも消すときは、`~/Library/Application Support/OtoWake BG` もゴミ箱に入れます。
- Windows：スタートメニューの「OtoWake BG」フォルダーの「OtoWake BG をアンインストールする」か、「設定」→「アプリ」→「インストールされているアプリ」から削除します。設定とデータ（`%APPDATA%\OtoWake BG` と `%LOCALAPPDATA%\OtoWake BG`）は残ります。

## 使うときのお願い

- 使う音は、あなたが使うことを許されているものにしてください。取り込みや加工が認められるかどうかは、音源の権利と、再生元のサービスの利用条件によって違います。詳しくは[リリースノート](release-notes.md)の「留意事項」にあります。
- パートの分け方は完全ではありません。聴いて確かめながら使ってください。
