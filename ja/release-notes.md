# OtoWake BG（おとわけびーじー）リリースノート

OtoWake BG は、ブルーグラスを演奏する人のための練習アプリです。いま鳴っている曲を、パートごとに分けて鳴らし直します。ボーカル、バンジョー、マンドリン、フィドル、ドブロ、ギター、ベースなどの音量を、自分で上げ下げできます。

この版は、Mac と Windows 向けの、機能を絞った最初の限定リリースで、バージョン 0.1.0 の**ベータ版**です。無料で使えます。正式版までに、動きや画面が変わることがあります。このノートでは、この版でできること、使う前に知っておいてほしいこと、クレジットを説明します。使い方の手順は、別の手引き（[Mac 版](manual-mac.md)、[Windows 版](manual-windows.md)）にあります。

## 1. OtoWake BG とは

### どんな人のためのアプリか

- 好きなバンドの録音に合わせて、自分のパートを弾いたり歌ったりして練習したい人
- 聴き取りたい楽器だけを大きくして、フレーズを耳で確かめたい人
- 速さを落としたり、キーを変えたりして、難しい所を繰り返し練習したい人
- 自分の演奏を録って、曲と一緒に聴き直したい人

### 何ができるか

使うのは、あなたが使うことを許されている音声ファイルか、パソコンで再生中の音です。アプリがその音をほぼリアルタイムで 10 のパートに分けます。

- ボーカル、バンジョー、マンドリン、フィドル、ドブロ、ギター、ベース、ドラム、ピアノ、その他

パートごとに音量を変えたり、消したりできます。弾きたいパートを消せば、その録音があなたの伴奏になります。

アコースティックなブルーグラスの編成（歌、バンジョー、マンドリン、フィドル、ドブロ、ギター、ベース）に合わせて作ってあります。

## 2. この版でできること

この版は、次の機能を使えます。

- **パートに分ける**：再生中の音（Mac の音、PC の音）や音声ファイルを、パートごとに分けて鳴らします。パートごとの音量調整、ミュート、ソロ（一つだけ聴く）ができます。
- **速さとキーを変える**：音の高さを変えずにゆっくり再生します。曲全体のキーを半音ずつ変えます。ボーカルだけ別のキーにもできます。
- **ループと範囲**：曲の一部を繰り返します。名前を付けて保存できます。ソロ（ブレイク）や歌の区間を、アプリが見つけて一覧にします（どちらも下書きです。歌の区間の分け方は、あらくなります）。
- **練習の道具**：いまの音を止めて伸ばす「音を伸ばす」（耳で音やコードを探すとき）、拍のクリック、音量グラフ、練習モード（自分の楽器を選んでパートの音量をまとめて設定）、練習曲の登録。
- **キー、BPM、コード進行**：曲のキー、テンポ、小節ごとのコードを推定して表示します（推定値です）。間違いは手で直せます。
- **自分の録音**：マイクで自分の歌や演奏を録り、同じ曲と一緒に聴けます。
- **タブ譜**：タブ譜の表示、編集、再生、移調、書き出しができます。写真や PDF のタブ譜は、読み取って下書きにできます（読み取りの対応は、Mac 版と Windows 版で違います。手引きを見てください）。
- **ノリ・チェック（試験的）**：楽器ごとの音の出だしの位置と、リズムのブレ、歌の音程を測ります。
- **MCP で AI アシスタントに採譜を頼む（試験的）**：あなたの AI アシスタントをアプリにつなぎ、選んだ区間の採譜を頼めます。音の候補は簡易な方法で拾うため、精度は高くありません。

今後、機能を増やす予定です。

## 3. 動作環境

### Mac

- macOS 14.2 以降
- Apple シリコンの Mac（Intel の Mac では動きません）
- 音が出るまで、数秒から十数秒かかります（音声ファイルは、2 回分けて平均するため、約 15 秒です）。パソコンの処理が間に合わないときは、音を先にためてから再生する方式に自動で切り替わります（後の「パソコンの性能と遅れ」を見てください）。

### Windows

- Windows 11（x64）
- DirectX 12 に対応した GPU を推奨します。GPU がなくても CPU で動きますが、処理が間に合わないことがあります。

### 共通

- 音声ファイルを開くとき、またはパソコンで再生中の音を取り込むときは、あなたが使うことを許されている音を使ってください（「留意事項」を見てください）。
- 「試験的」の AI 採譜を使うには、MCP に対応した自分用の AI アシスタントが別に必要です。

## 4. 留意事項（使う前に知っておいてほしいこと）

### 4-1. 分離は完全ではありません

アプリは、混ざった音から AI で各パートを推定して取り出します。取り出した音には、ほかのパートの音が少しずつ混ざります。

- **ドブロ**：分けられるのは、ある程度までです。精度はまだ低く、ほかの楽器がドブロの側に入ったり、ドブロが別のパートに入ったりします。
- **歌は「小さくする」もので、「消す」ものではありません**：ボーカルを 0% にしても、声が薄く残ることがあります。きれいなカラオケを作るアプリではありません。
- **ベースへの混ざり**：ギターの低い音や声が、ベースのパートに出ることがあります。
- **バンジョーへの混ざり**：ギターの高い音が、バンジョーのパートに入ることがあります。
- **ギターへの混ざり**：マンドリン、フィドル、歌が、ギターのパートに入ることがあります。
- **得意な編成**：アコースティックなブルーグラスの編成です。ドラム、ピアノ、エレキ楽器の多い曲や、ほかのジャンルの曲は、うまく分けられないことがあります。

分け方は、曲、録音、パートによって大きく変わります。聴いて確かめながら使ってください。

### 4-2. 表示される数字は推定です

- **キー、BPM、コード進行**：音から推定した値で、間違うことがあります。BPM は、実際の倍や半分で出ることがあります。コードは、メジャー、マイナー、セブンスだけを見分けます。速いコードチェンジや、伴奏の薄い所、ソロの間は間違いやすくなります。
- **ソロ（ブレイク）や歌の区間**：アプリが見つけた「下書き」です。歌の区間の分け方は、特にあらくなります。名前や境目が違うことがあります。聴いて確かめてください。
- **ノリ・チェックの数値**：目安です。演奏の良し悪しを決めるものではありません。
- **写真や PDF から読み取ったタブ譜**：下書きです。すべての小節に「?」の印が付きます。元の譜面と見比べて直してください。

断定して表示されているものはありません。アプリの数字より、あなたの耳を信じてください。

### 4-3. 音の権利は、あなたの責任です

音声の取り込みや加工が認められるかどうかは、音源の権利と、再生元のサービスの利用条件によって違います。パソコンで技術的に取り込めることは、利用が許されていることを意味しません。使うことを許された音声だけを選んでください。

DRM（コピー防止）付きの音声ファイルは開けません。また、保護された音声は、取り込めないことがあります。

### 4-4. 保存するもの、保存しないもの

- 通常の再生では、取り込んだ曲の音も、分けた音も、ディスクに保存しません。音声はメモリの上を流れるだけです。
- 処理が追いつかないときに使う「ためて再生」でも、ためる音はメモリの上だけです。再生が終わるか、OFF にするか、アプリを終えると捨てます。
- 保存するのは、主に次のものです。
  - **自分の録音**：あなたのマイクの音だけです。曲の音は保存しません。曲との位置合わせには、音に戻せない特徴量だけを保存します。
  - **タブ譜、保存した範囲と区間リピート、設定**
  - **演奏の測定**：「演奏の測定を保存する」をオンにしたときだけ、数値（音声ではありません）を保存します。
  - **ファイルの履歴**：自分で開いた音声ファイルの名前と場所の一覧です。
  - **採譜用の分離音（試験的な機能を使ったとき）**：選んだ区間の分離音を、あなたのパソコンの中に保存します。次の採譜が終わると、前のものを削除します。
- 保存先は、Mac 版が `~/Library/Application Support/OtoWake BG/`、Windows 版が `%APPDATA%\OtoWake BG` と `%LOCALAPPDATA%\OtoWake BG` です。
- 保存した情報は、アプリの中から個別に、またはまとめて消せます（自分の録音、測定の履歴、ファイルの履歴）。

### 4-5. 試験的な機能

「試験的」と表示されている機能は、まだ試している段階です。

- **ノリ・チェック**：結果は、分離の品質に左右されます。分離がうまくいかない曲では、数値も当てになりません。
- **AI 採譜（MCP）**：
  - 採譜はアプリの中の自動採譜ではありません。あなたが自分で用意した AI アシスタントが行います。アプリだけでは採譜しません。
  - アプリが AI に渡す材料は、拍、音名、音の候補などの数値です。音声そのものを自動で送ることはしません。ただし、選んだ区間の分離音は、あなたのパソコンの中に保存してあり、AI アシスタントが求めると、1 回に最大 30 秒ずつ渡されます。AI アシスタントがその音をどう扱うかは、そのサービスの規約によります。使う前に確かめてください。
  - 音の候補は、音声から簡易な方法で拾ったものです。あまり正確ではないため、AI の採譜には、間違いや、弾けない運指が多く含まれることがあります。AI が出した採譜は、必ず耳で確かめてください。
  - Mac 版では、AI に採譜を頼むボタンは、最初は再生画面に出ません。詳細設定の「一般」の「MCP 設定 (試験的)」で、「再生画面に「AI に採譜を頼む」ボタンを出す」をオンにします。

### 4-6. パソコンの性能と遅れ

リアルタイムで分けるには、ある程度の性能のパソコンが必要です。

- 音を取り込んでから、分けた音が出るまでに、数秒から十数秒以上かかります。音声ファイルは、曲を 2 回分けて平均するため、約 15 秒かかります（詳細設定でオフにすると、6〜7 秒短くなります）。再生が始まった後も、元の音より遅れて聞こえます。動画を見ながら使うと、映像より音が遅れます。
- パソコンの処理が間に合わないとき（1 チャンクの処理時間が 5 秒の 80% 以上のとき）は、自動で「ためて再生」に切り替わります。この方式では、再生が始まるまでの待ち時間が長くなります。また、ためている間は、自分の録音ができません。
- 詳細設定の「分離」の「再生方法」で、方式を選べます（Mac 版は「自動」「常にリアルタイム」「常にためる」、Windows 版は「自動」「リアルタイム」「ためて再生」）。リアルタイムに固定して処理が間に合わないと、音が途切れます。
- 音量、パートのオンオフ、キーを変えても、変更が聞こえるまでに少し時間がかかります。
- 具体的な動作機種の一覧は、この版では用意していません。

### 4-7. アプリが求める許可

- **Mac の音の取り込み**：Mac で再生中の音を取り込むときに、macOS が許可を求めます。「システム設定」の「プライバシーとセキュリティ」にある「画面収録とシステムオーディオ録音」で許可します。取り込んだ音は保存しません。
- **マイク**：自分の録音をするときに、許可を求められます。保存するのはマイクの音だけです。Windows 版は、Windows の設定で、デスクトップアプリにマイクの使用を許可します。
- **カメラ**：タブ譜を撮るときだけです。Mac 版は、近くの iPhone のカメラ（連係カメラ）を使います。Windows 版は、タブ譜の窓の「カメラで取り込む」で使います。残るのは、撮った写真だけです。
- **ミュージックなどの操作（Mac 版）**：曲名や再生位置を読み取り、区間リピートで再生位置を戻すために、ミュージックなどを操作します。必要になったときに許可を求められます。

### 4-8. 数値と採譜を使うときの注意

- 数値や採譜を、そのまま教材や配布物に使う前に、必ず聴いて確かめてください。

## 6. 感想と不具合の連絡

感想や不具合は、次のどちらかのダイレクトメッセージで送ってください。

- X の @OtoWakeBG へのダイレクトメッセージ
- Substack のダイレクトメッセージ

メールでの受け付けはしていません。

不具合を知らせるときは、次を添えてもらえると助かります。

- 使っている OS とそのバージョン、Mac の機種名か PC の CPU と GPU
- どの操作で、何が起きたか
- Windows 版は、詳細設定の「診断」タブの「診断情報をコピー」でコピーできる内容。音声や曲名は含まれませんが、ファイルの場所にユーザー名が含まれることがあるので、送る前に確かめてください。Mac 版は、エラー表示の「詳細をコピー」の内容。
